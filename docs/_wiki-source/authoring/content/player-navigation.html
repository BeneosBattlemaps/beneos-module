Players move between maps too, not just DMs. Their character actors travel on their own at specific points on the map, with no DM input needed. This runs on the Multilevel Tokens module, so make sure it is installed and active. Using it is dead simple. Want the technology, or to place your own navigators? Read the Multilevel Tokens deep dive. You do not have to, since we prepared everything for you.

How player teleporters work

Multilevel Tokens connects two places: an origin and a destination. We have pre-set where each player teleporter leads. Every teleporter field (visible only to DMs) carries a journal icon. A player clicks it, their character token jumps from origin to destination, and the scene changes for that player alone. If the DM clicks a journal icon in a teleporter zone, every token moves, player and non-player alike.

You are not obligated to let players roam freely, but it can drive exciting, narratively gripping exploration. Keep track of where each player is. When a player announces a scene change, that is your cue to describe the new location properly. Two icon types control the teleporters.

What the icons mean

IconMeaning
Player navigator. The standard icon players see once they get close enough. They cannot see it through walls; they must reach the scene exit to interact. If a player clicks it while a character they control stands in the teleport zone (invisible to them), that character travels to the target scene, and the scene changes for that player alone.
Hidden DM navigator. Same effect as the player navigator, but invisible to players and unusable by them. It serves non-obvious paths: secret doors, routes to be discovered or opened later. When you decide players can move on, click it and they teleport to the destination. Great for traps, cleared paths, cracked doors.

Who sees which icons

Players see a journal icon only if its journal has been released to them or to all players. Place five icons but release each journal to a single player, and each player sees only their own. Use this to give players private notes, or to keep DM navigation separate from player navigation.

Set a journal's permission like you would a token's. Open the journal browser via Journal in the top-right navigation bar. Right-click the journal and choose Configure Ownership. All Players grants everyone in the world access (DMs excluded). Below that, set per-player rules. Usually you grant the intended player permission and leave the rest alone.

  • Owner: full reading and editing rights.
  • Observer: can see the journal, cannot edit it.
  • None: can neither see nor edit it. This is the default for all DM navigation journals, like the Point of Interest Teleporter.

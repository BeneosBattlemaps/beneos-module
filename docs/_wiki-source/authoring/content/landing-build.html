Before you read: nothing here is required to use Beneos. This page is for the GM who has seen the Avernus and Barovia hubs and thought, I want one of those for my own world.

A landing page looks fancy, but it is only ever the same four ideas wearing different art. Once you can name them, you can build a hub for any campaign, or take one of ours apart and rebuild it as your own.

The recipe

  1. A set of scenes. One home page plus a scene for each thing your players need: a map, a headquarters, a cast page, whatever your story wants. A landing page is just these scenes grouped in a folder.
  2. A navigation bar. On every scene, a small menu that jumps to the others. This is the one moving part, and it runs on Monks Active Tile Triggers.
  3. Reveal on demand. Content that starts hidden and appears when the party earns it: an NPC, a contract, an artefact, a vehicle. In Foundry that is nothing more than a tile or drawing you right-click and Toggle Visibility State.
  4. Points of interest. On the map scenes, journal markers players can open, and travel through. See Point of Interest Teleporters.

Build it step by step

1. Lay out your scenes

Decide what your hub needs and make a scene for each, plus a home page. Keep them together in one Scene folder so the set is easy to find and move. The fastest start is to copy one of our landing pages and swap the art, since the wiring is already done.

2. Wire the navigation

Give the home page a row of buttons, one per scene, then repeat that bar on every scene so players can move freely from anywhere. Each button is an invisible clickable tile over a visible text label, with a Change Scene action behind it. The Monks Active Tiles deep dive has a full walkthrough for building a navigator, and copying an existing button is by far the easiest way in.

3. Set the home page active by default

Make the home page the scene players see when they log in, and keep it active at the start of each session. From there they reach everything you have opened to them.

4. Hide what is not earned yet

Start with only the essentials visible, and keep the rest hidden. As the campaign moves, reveal a navigation point, an NPC, or a reward by toggling its visibility. That slow unveiling is what makes a hub feel alive instead of a static menu.

5. Dress it up

A landing page is a stage, so light it. Add an ambient track under the scene's Ambience tab, and use FXMaster for weather and mood. A session title on the home page, edited with the drawing tools, sets the tone before anyone speaks.

Link a spot to its guide

You can drop a help marker anywhere on a scene that opens the documentation straight to the right place, so a curious player clicks once and lands on the exact guide. Place a map Note with the Beneos help icon, then use its Label to point it:

  • Just the docs: a plain help note (no marker) opens the documentation front page, the same as the help icon on every Beneos scene.
  • A specific article: add @doc[landing-avernus] to the label and it opens that article.
  • A specific section: add @doc[landing-avernus#la-garage] and it jumps straight to that part of the article.

The @doc[...] marker is never shown on the map; only the text before it is, so a label like Garage guide @doc[landing-avernus#la-garage] reads simply as "Garage guide". The page name is the article's key from the documentation sidebar, and the section names come from each article's own headings. Left click or right click both open it.

Learn from the ones we shipped

The quickest teacher is a working example. Open the Descent into Avernus hub for the full toolkit, a headquarters table, a hexcrawl world map, a garage of rewards, or the Curse of Strahd hub for a book of quests and a wall of faces. Take the parts that fit your story and leave the rest.

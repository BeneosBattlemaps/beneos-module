Beneos battlemaps are not flat images you drop in and align by hand. They are animated, professionally pre-configured Foundry scenes. Video background, walls, lighting, ambient sound, and intro sequences are set up in advance, including day and night variants and static fallbacks where they make sense. Open a scene and it is ready to play.

What a release contains

Most releases bundle several connected maps for one location, not a single standalone map. A typical release includes:

  • An overview map that ties the location together.
  • Regional and world maps that place it in the wider world.
  • Sceneries, cinematic immersive views for role-playing moments.
  • Battlemaps, the tactical views you actually fight on.
  • Handouts, optional immersive shots you can show players.

Teleporters link all of them, so you move between them with one click. See DM navigation for jumping around as the DM.

Animated, with fallbacks

The maps come alive: water moves, torches flicker, weather drifts across the scene. Every animated map ships with a static fallback, so you can switch to a still image any time, for example on a weaker machine. Many maps include day and night variants too. You stay in full control of how the scene looks and runs.

How to install them

Battlemaps install through the Beneos Cloud window. Pick a release, choose 4K or HD, download. See Installing content for the steps, and Performance and resolution for help choosing 4K versus HD.

After install, the scenes land in your Scene Directory fully set up: walls, lighting, sound, teleporters, and intros all in place. Nothing to configure. To set music and ambient volume, see Ambience and sound.

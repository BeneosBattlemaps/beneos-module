Čtyři kroky

  1. Nainstaluj a aktivuj doprovodné moduly. Obsah Beneos se opírá o hrstku bezplatných modulů pro Foundry. Úplný seznam a jednorázové nastavení najdeš v kapitole Požadavky.
  2. Otevři okno Beneos Cloud pro procházení a stahování map, tokenů, itemů a kouzel. Viz Okno Beneos Cloud a Instalace obsahu.
  3. Vyber rozlišení. Většina releasů ti při instalaci nechá zvolit 4K, nebo HD. Nejsi si jistý? Přečti si Výkon a rozlišení.
  4. Otevři scénu a hraj. Zdi, osvětlení, zvuk i teleporty jsou už nastavené. Jak se pohybovat mezi mapami, se naučíš v kapitolách Navigace PJ a Navigace hráčů.

一個 Beneos 帳號就能解鎖你擁有的一切，無論在 Foundry 還是網路商店。不需要密碼：只要你的電子郵件和一組一次性驗證碼，大約一分鐘搞定。

為什麼需要帳號

帳號是 Beneos 得知哪些內容屬於你的方式。Patreon 會員資格、商店購買、免費發行版：全都掛在你的帳號上，模組讀取這份清單來決定你能安裝什麼。沒有帳號，什麼都不會解鎖。就算免費帳號也值得申請：各種類型都有免費內容，免費的地圖、生物、戰利品和法術。

使用你的 Patreon 電子郵件

這是唯一必須做對的事。用你在 Patreon 上使用的同一個電子郵件地址登入。這樣做的話，你第一次登入的那一刻，會員資格就會自動連結，你的內容也就直接到位。用了不同的電子郵件？本頁底部有解法。

首次登入即建立帳號

沒有另外的註冊流程。你在 Foundry 裡第一次登入，輸入電子郵件並確認的那一刻，帳號就當場建立。就這麼簡單。有兩個入口：

  • 模組設定：在 Foundry 設定中找到 Beneos 模組，點擊登入 Beneos Cloud。
  • Cloud 視窗：開啟 Cloud 視窗，從 Home 分頁登入（1）。

登入步驟

  1. 點擊登入並輸入你的電子郵件（Patreon 那一個），然後按傳送驗證碼。
  2. Beneos 會寄給你一組一次性驗證碼。全程沒有密碼。
  3. 輸入驗證碼（1）並驗證。第一次登入時，這一步會當場建立你的帳號。
  4. Beneos 在背景檢查你的會員資格，然後你就登入了。頁尾現在會顯示已連線。

沒收到驗證碼？檢查垃圾郵件資料夾，等過短暫的冷卻時間後再傳送一次（2）。

用了和 Patreon 不同的電子郵件？

沒問題，也不需要重來。在網路商店開啟你的收藏庫，前往你的 Beneos 使用者設定，在那裡加入你的 Patreon 電子郵件。兩個地址從此都計入你的帳號，你的會員資格也隨之解鎖。詳情見連結你的帳號。

它解鎖什麼

免費帳號可以立即取得免費內容。兩個 Patreon，Beneos Battlemaps 和 Beneos Creatures, Spells & Loot，補上其餘的部分；各階級提供的內容見 Patreon 階級與商店。鎖定的內容仍然會顯示在 Cloud 中並帶有加入提示，讓你隨時看得到加入會員能多獲得什麼。已經登入了？去安裝點什麼吧。

Beneos 地圖是影片，而影片對機器的要求比靜態圖片高。如果場景出現卡頓，你手上有幾個實在的調整手段。它們都不會犧牲真正重要的畫質。

4K 還是 HD？

大多數發行版本在安裝時可以選擇解析度：4K 或 HD。4K 在大型高解析螢幕上更銳利，但會吃掉更多磁碟空間、視訊記憶體與 GPU。HD 更輕量，在桌面距離下看起來依然出色。不確定？先選 HD，之後隨時可以再抓 4K 版本。你在雲端視窗裡做這個選擇。

切換到靜態檢視

每張動畫地圖也都附帶靜態版本。如果你的系統在某個場景上跑不動，就把那一張地圖切換成靜態版本，不論是場景畫面還是戰鬥地圖，卡頓立刻消失。不需要重新下載。在場景目錄中對場景按右鍵，選單會顯示適用於它的那個切換選項：

  • 在動畫場景上你會看到 Use Static Map（1），切換成靜態圖片。
  • 在靜態場景上你會看到 Use Animated Map，切換回影片。

在效能較弱的機器上，這是效果最大的單一手段。平常用靜態版本遊玩，到了揭幕時刻再切回動畫。

什麼在吃你的效能

  • 動畫背景是大宗。它全程都在解碼影片。
  • FXMaster 效果（天氣、粒子）疊加在上面。粒子越多，成本越高。把它們調低。
  • 前景影片圖塊（搖曳的樹木之類）在它們所在之處都是額外的影片圖層。

在效能較弱的機器上

  • 安裝 HD，不要 4K。
  • 平常玩靜態版本，只在需要驚豔的時刻切到動畫。
  • 在任何拖慢的場景上精簡 FXMaster。
  • 關閉其他吃資源的分頁與程式。Foundry 在瀏覽器中執行，記憶體要和其他所有東西共用。

本頁涵蓋 Beneos 內容與 Beneos 模組的健康警告、年齡指引，以及使用與授權條款。想更瞭解我們是誰，請見關於我們頁面。

致癲癇使用者的健康警告

使用動畫化的 Beneos Battlemaps 時，請留意潛在的健康風險，特別是對光敏性癲癇較敏感的人。部分地圖包含可能誘發癲癇發作的元素：例如某些地圖上暴風雨動畫產生的閃電，會出現類似頻閃的閃光，可能成為誘因。如果你或你團體中的任何人有癲癇或抽搐發作的病史，請在使用這些動畫地圖前諮詢醫療專業人員。我們也建議定期休息、在光線充足的房間遊玩，並避免在疲勞或睡眠不足時遊玩，因為那會提高發作的風險。

年齡分級資訊

我們的內容未經任何公開分級機構評定。我們致力於創作不美化暴力或殘忍行為的內容。雖然我們的奇幻冒險地圖可能包含少量暴力痕跡或描繪怪誕的生物，但這些元素從來不是重點。本著安全與包容的遊戲環境精神，我們自行將內容評定為適合 12 歲以上使用。我們建議家長親自檢視這些地圖，或參考我們的一般年齡指引，來決定內容是否適合他們的孩子。我們的承諾是提供沉浸式的奇幻體驗，同時不損害使用者的身心健康與安全。

一般授權資訊

除非另有說明，Beneos 模組的程式碼是 Beneos Battlemaps 的智慧財產，總部位於德國。

搭配 FoundryVTT 使用

你可以自由地將 Beneos 模組與 FoundryVTT 一起使用。模組可透過 GitHub 或 FoundryVTT 模組瀏覽器安裝。使用或安裝模組不收取任何費用。它的目的是讓 Beneos Battlemaps 的產品對社群而言更容易取得、更容易使用。

在直播與影片中使用 Beneos 素材

你可以毫無問題地在營利的直播或影片中使用 Beneos 素材（戰鬥地圖、Token、法術、物品等等）。基於公平原則，我們希望你口頭提及或在畫面上標註出處，也永遠歡迎你分享你們遊戲的連結，讓我們能在社群媒體上轉發。若直播預期觀眾達 800 人以上，或影片預期觀看數達 100,000 次以上，請事先與我們聯絡。

再散布

未經另行協議，不得在其他產品中再散布 Beneos 內容，或提供其下載。如果你有想法，或想以本頁未涵蓋的方式使用我們的內容，請與我們聯絡，我們會好好談談。

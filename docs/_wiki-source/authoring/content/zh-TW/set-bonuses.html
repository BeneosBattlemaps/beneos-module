收集魔法物品很有成就感。收集彼此成套的物品更棒。Beneos 套裝加成會獎勵契合多件相同 Origin 物品的玩家，把一堆戰利品變成不斷成長、主題一致的裝備組。一個角色對單一 Origin 投入越多，回報就越強、越有個性。

三個階級

契合相同 Origin 的物品會解鎖分階級的加成。依契合數量分為三個階級：

階級已契合物品你獲得什麼
Echo of Origin1一個小型被動效果，或每日一次的能力。
Resonance2一個更強的主動或被動效果。
Perfect Harmony3一個頂點效果，該 Origin 的完整體現。

融合儀式

達到 Perfect Harmony 後，角色可以進行融合儀式，把三件物品合而為一件神器。純粹的好處：融合後的神器在後續計算中仍然算作三件物品，所以玩家保有階級，同時擺脫三件獨立物品占用的物品欄與契合額度。這是對投入一個 Origin 的乾脆獎勵。

稀有度調整值

套裝效果並非全是固定數值。許多效果會隨稀有度調整值縮放：也就是你已契合物品稀有度的總和。每個稀有度都有對應數值：

稀有度數值
普通1
非普通2
稀有3
非常稀有4
傳說5

把已契合物品的稀有度加總，就是你的稀有度調整值，上限為 15。想追求套裝效果的最強版本，代表你要的不只是三件同 Origin 的物品，而是三件強力的物品。

Named 與 Generic

物品是 Named 還是 Generic，會改變它計入套裝的方式：

  • Named 物品計入 Resonance 與 Perfect Harmony，所以它們絕對能堆高你的階級。
  • 但單獨一件 Named 物品不會給予單件的 Echo of Origin。入門階級來自 Generic 物品。

所以一件著名神器能完美嵌入已經成形的套裝，但它無法獨力撐起一套。

Beneos Sets 分頁

每張角色卡都會多出一個 Beneos Sets 分頁，攤開你的進度。它按 Origin 顯示你的契合數量、稀有度調整值、生效中的加成，以及距離下一階級的進度（1）。一眼就能回答「我的裝備合起來能做什麼，我還差一件什麼」。

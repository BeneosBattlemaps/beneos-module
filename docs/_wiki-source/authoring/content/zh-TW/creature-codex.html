一隻 Beneos 生物不只是數據方塊加上漂亮的 Token。每隻怪物都附帶 GM 在桌上真正需要的東西：怎麼操作它、它危險在哪裡、該朗讀什麼，以及如何讓它的登場震撼全場。這一切都收錄在 Creature Codex 裡。我們提供 700 多隻生物，其中 400 多隻來自 SRD，300 多隻是 Beneos 原創設計，每一隻都有自己的詳細頁面。

把生物帶進你的世界

生物來自雲端。開啟 Beneos 雲端視窗，進入生物瀏覽器，安裝你想要的那一隻。安裝會在你的側邊欄建立一個角色（Actor），附帶乾淨的 2.5D Token，隨時可以拖到畫布上。從那一刻起，這隻生物就是你的了，不論線上或離線都能使用。

開啟 Codex

Codex 是模組內的專屬視窗，一個以路由為基礎的中樞，讓你在生物之間跳轉而不會迷失方向。有兩種進入方式：

  • 從雲端視窗開啟生物的詳細頁面，再進入它完整的 Codex 條目。
  • 從生物的角色卡，上面有一個按鈕直接帶你前往它的頁面。

生物頁面提供什麼

每個頁面都分成清楚的區塊，讓你在戰鬥途中不必捲過大段文字牆就能找到需要的內容。

總覽

快速掌握重點，開頭是一段可朗讀的戰鬥開場：一小段富有畫面感的文字，在戰鬥開始的那一刻朗讀。遭遇以一個場面揭幕，而不是一次擲骰。

戰術

這隻生物怎麼打。它的作戰方式、它想站在戰場的哪個位置、它害怕什麼、它帶來哪些威脅。放下 Token 之前先掃一眼這裡。

能力

它的招牌能力，依挑戰等級（CR）調整，正是這些讓它顯得獨一無二而不是換皮怪。Combat Autopilot 能幫你在遊戲中追蹤這些能力。

傳說

背景故事，讓你能回答玩家的問題，並把這隻生物編進你的世界。

伏筆

在遭遇之前拋出的簡短暗示，用來累積不安感，還有它倒下時的死亡朗讀文字。想把這些用得漂亮，請見伏筆與沉浸感。

頁面上的工具

  • Combat Autopilot：針對單一生物的助手，讓戰鬥不脫軌。請見 Combat Autopilot。
  • 可列印 PDF：乾淨的單生物 PDF，適合桌上使用或備戰準備。

為沉浸感而生

Beneos 生物的設計目標是在畫布上栩栩如生。Token 帶有投影陰影與柔和光暈等特效，乾淨的 2.5D 美術即使在擁擠的場景裡也能一眼辨識。Codex 為這份存在感配上相稱的文字，讓你把怪物當成一個場面來主持，而不是一個數字。

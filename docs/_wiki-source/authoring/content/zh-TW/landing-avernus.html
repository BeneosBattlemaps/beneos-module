閱讀之前：著陸頁開箱即用。設為啟用、邀請你的玩家，它就能運作。以下內容是給想要把它用得得心應手，或想把它改造成自己戰役的 GM。它是為地獄主題的遊戲打造，並與 Descent into Avernus 這類冒險搭配，但沒有什麼能阻止你把它用在任何煉獄故事上。

阿弗納斯著陸頁不是單一場景。它是一小組場景，串接成一個玩家可以自行遊走的樞紐：一個首頁、一張總部桌面、一頁他們見過的面孔、一張地獄世界地圖，以及一間存放他們擄獲的戰爭機器的車庫。你隨著戰役的推進逐步揭露每個部分。

著陸頁與導航

這是玩家登入時看到的第一個畫面，所以在遊戲開始時請預設保持它為啟用狀態。玩家從這裡可以抵達你為他們解鎖的每一個場景。一開始只有玩家桌面和角色頁面是開放的；其餘的，世界地圖、車庫，等故事到了再由你解鎖。

遊戲標題

在著陸頁上為每次遊戲取一個有氣氛的標題：一個場次編號，加上一絲即將到來之事的不祥暗示。在任何人開口之前就先定下基調。從左側工具列選取繪圖工具，雙擊標題文字即可編輯。如果它不適合你的故事，也可以把標題連同橫條整個隱藏。

導航如何運作

每個按鈕由兩個圖塊組成：一個隱形的可點擊圖塊疊在可見的文字標籤上，由 Monks Active Tile Triggers 驅動。要為玩家開放一個導航點：選取 Tile Controls，把隱形圖塊挪開，右鍵點擊下方的文字圖塊並切換可見狀態使其顯示，再把隱形圖塊滑回標籤上方並鎖定，最後右鍵點擊隱形圖塊並開啟它的啟用狀態。在其他頁面上也照做，這樣無論玩家在哪裡，導航都保持順暢。

如果 MATT 正處於更新空窗期

在 Foundry 大版本升級之後，Monks Active Tile Triggers 往往是最後跟上的模組之一。針對這些短暫的空窗期，這些頁面附帶一套由普通日誌圖示組成的備援導航，與 Beneos 地圖上其他地方使用的相同。把那些日誌的擁有權授予你的玩家，並把圖示拖到導航列上，他們就能右鍵點擊來移動，直到 MATT 更新為止。一百次裡有九十九次你可以無視這一段。

背景音樂

這裡的每個場景都帶有自己的音源，進入場景時開始播放。共用同一曲目的場景在你移動時會無縫接續播放。要更換或靜音，右鍵點擊場景，開啟設定，在環境分頁下清除或替換場景播放清單。更多資訊見環境音與音效。

玩家桌面

玩家桌面是隊伍的總部，他們需要的一切都集中在一個桌面上。你可以把它演繹成洞穴裡的基地、地城裡的據點，隨你的故事安排。如果你跑的不是官方模組，可以關掉右上角的動態標誌，換上你自己的。

煉獄契約

當玩家簽下惡魔的交易時，右鍵點擊契約圖像並使其可見，把那份契約揭示在桌面上。把實際條款寫進一個日誌、分享出去，再拖到可見的契約上，玩家就能隨時翻閱自己簽下的交易。

靈魂硬幣

契約旁邊是一個用來記錄靈魂硬幣的小寶箱。隱藏覆蓋它的圖塊即可為玩家打開寶箱，然後隨著他們的積蓄增減來顯示或隱藏個別硬幣。下方的小計數器可以一眼讀出總數，最多到十九。

任務日誌

桌上的大書是隊伍共用的任務日誌。用文字工具輸入任務標題，工作完成時勾選核取方塊圖塊，或給完成的任務打上 X。這本書也能放講義和圖片，所以它同時是隊伍需要記住的一切的釘板。

玩家角色卡

右下方是一排玩家角色卡，為六人隊伍準備了六張。為每位玩家啟用一張，把占位名稱改成你們的角色，然後透過開啟設定和代表的 Actor 把每張卡的隱藏 Token 連結到正確的角色。之後玩家就能雙擊自己的卡片打開角色、查看物品欄和法術，或直接在桌面上調整生命值。需要超過六張？複製一張卡片並用同樣方式設定即可。

角色頁面

戰役裡的面孔累積得很快。這個頁面讓你的玩家記住他們見過誰、在哪裡見過。角色依地點分組，分布在三個子頁面上，足以容納一整個戰役的登場人物。

每張肖像都是你 Actor 目錄中的真實 Actor。要揭示一個，選取 Token Controls，點擊該角色的 Token，然後右鍵點擊並切換可見狀態。玩家永遠看不到數值表，但面孔一旦可見，他們把游標移上去就能讀到名字。要加入你自己的 NPC，把 Actor 拖到場景上，開啟它的 Token 設定，並把顯示名稱設為「任何人懸停時」，這樣你揭示之後玩家就能讀到名字。

地獄世界地圖

別被這個場景嚇到。它裝載了大量 GM 機關，但你的玩家永遠只會看到地景和自己的 Token。你的團想用多少就用多少；一次性團可以無視所有標記，仍然得到一張好地圖。

穿越地獄的六角格探索

地圖由六十個六角格組成，編號 A1 到 J6，每格都是獨立的生態：沙漠、燃燒的平原、熔岩地帶。每個六角格至少有一個興趣點，以日誌圖示標記，雙擊即可閱讀。就算完全不碰興趣點，光是這張格網就能跑一場穿越地獄荒原的生存跋涉。它建立在 The Alexandrian 推廣的結構之上，並以第三方和自製內容擴充，每個外部來源都在各自的興趣點裡附上連結。

解讀興趣點顏色

興趣點圖示以顏色編碼，讓你一眼看出每個點的出處：藍色是官方 Descent into Avernus 內容，紫色是來自 The Alexandrian 的免費第三方素材，黃色是可以在別處購買的額外第三方內容，每個日誌裡都註明了連結和作者。

向玩家揭示一個地點

當隊伍發現一個地方時，把日誌授予他們：選取日誌筆記，點擊六角格上的圖示，在日誌分頁中找到它的標題，右鍵點擊，配置所有權，設為所有玩家觀察者。現在他們就能自行打開並探索。戰爭迷霧會遮住其餘部分，直到他們的 Token 抵達。

兩種玩法

你可以只在這張全域地圖上跑完一切，對大多數團來說已經足夠；或者把六個字母區域（A 到 F）當成地城的六個房間，逐一進入各自的詳細區域地圖。細節就在下面。

更簡潔的地圖，以及未來擴充

如果詳細格網太繁雜，圖塊下方有一個興趣點較少的精簡版本可以切換。而且地圖會成長：灰色的圖示是尚未推出的地點，安裝對應的發行版後會自動亮起。把游標移到圖示上就能看到它屬於哪個發行版。

區域地圖

區域地圖是全域地圖上單一區域的特寫，每張都以完整品質繪製，讓每個興趣點都清晰可辨，就像電玩遊戲的一個關卡。六角格布局與全域地圖完全一致，所以連結關係相同；改變的只有細節。你的玩家以隊伍為單位逐格移動，並可以離開一個區域進入下一個。

區域邊緣設有以箭頭和日誌圖示標記的導航六角格。站在上面的 Token 可以朝箭頭指向的方向移動，你點擊日誌的眼睛圖示即可觸發移動。左上角的小地圖讓所有區域一覽無遺。在區域地圖上，興趣點列在右側而不是放在六角格上，這避免了誤點把人傳送走。每個區域還有自己的移軸攝影場景畫面，把世界呈現成一座小小的立體模型，如果這能為你的桌面增添沉浸感的話。

車庫

車庫是隊伍炫耀他們奪來的煉獄戰爭機器的地方。它一開始是空的，只有一個動態背景，隨著玩家贏得載具而逐漸填滿。我們提供五輛；一次發放一輛，或者改停你自己設計的載具。

要揭示一輛載具，選取 Tile Controls，用選取繪圖工具點擊該機器，然後右鍵點擊並切換可見狀態。用繪圖工具對它的名牌做同樣的操作，銘牌就會出現在旁邊。

一個 GM 技巧：把車庫、桌面和其他後間編進故事，作為隊伍可以踏入的口袋次元，一個用於談判、儲物或炫耀車隊的移動基地。為了避免它變成免費的安全屋，給它加點利齒：這地方是為惡魔建造的，所以酷熱難耐，人類在裡面待一小時就要承受一級力竭。

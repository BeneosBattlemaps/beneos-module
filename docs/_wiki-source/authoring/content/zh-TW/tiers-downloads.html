Beneos 建立在兩個 Patreon 和一個商店之上。你需要哪一個，取決於一件事：你實際怎麼玩。以下是全貌，長話短說。

Beneos Battlemaps：兩個階級，兩種玩法

這個 Patreon 有兩個獨立的階級。它們不是疊加的。選擇符合你桌面的那一個。

階級你獲得適合你，如果
Tier 1, Tableplay高解析度影片格式的地圖（MP4）你在實體桌面遊玩，或使用 Foundry 以外的 VTT
Tier 2, FoundryVTT完成品的動態 Foundry 場景，一鍵進入你的世界你在 Foundry VTT 中主持遊戲

用 Foundry？那就是 Tier 2。整個場景建置完畢送達：牆體、光照、音效、傳送點，一應俱全。Tier 1 則是把原始地圖影片交到你手上，正適合放在桌邊的電視上或其他 VTT 中使用。

Beneos Creatures, Spells & Loot：All Unit 階級

一個 Patreon，一個階級。All Unit 階級解鎖我們在這一邊製作的一切：每隻生物、每個法術、每件物品。你可以從 Cloud 視窗直接安裝到 Foundry，它們附帶各自的圖鑑頁面、Origins 以及其餘所有內容。

Beneos 商店

想不加入會員只買單一發行版？Beneos 商店讓你購買一張地圖或一隻生物並永久保有。它仍在上線過程中，所以目前請把它當作第二扇門，而不是正門。

免費

免費的 Beneos 帳號已經能讓你取得各種類型的免費內容：免費的地圖、生物、戰利品和法術，外加靜態圖片。它不花一毛錢，是看看 Beneos 適不適合你桌面的最簡單方式。

在你的網路商店收藏庫中，每個發行版都並排提供兩種下載：Tableplay 影片（1）和 Foundry 場景（2）。

實際取得的方式

在 Foundry 中，開啟 Beneos Cloud 視窗並安裝你擁有的內容。想把檔案握在手裡？從你的網路商店收藏庫下載 ZIP。無論哪種方式，請確認你的帳號已連結，你的存取權限才會被識別。

下載連結與你的帳號綁定。請勿分享，它們帶著你的名字和你的存取權限。

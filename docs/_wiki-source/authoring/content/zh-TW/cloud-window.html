Beneos Cloud 視窗是你瀏覽、預覽和安裝所有 Beneos 內容的唯一入口：生物、戰利品、法術和地圖。它既是商店櫥窗也是安裝程式，而且你完全不必離開 Foundry。安裝的內容會直接進入你的世界。

開啟方式

點擊 Foundry 左側工具列（畫布上的垂直工具條）中的 Beneos 圖示（1）。工作時可以讓視窗保持開啟，隨手把內容拖出來使用。

分頁

視窗頂部有五個分頁（1）：

  • Home（首頁）：新聞、更新日誌，以及登入的地方。
  • Creatures（生物）：2.5D 和 Top-Down Token，每個都附有 Actor 和圖鑑頁面。
  • Maps（地圖）：動態且完整建置好的戰鬥地圖場景。
  • Loot（戰利品）：物品與裝備，附有各自的 Origins。
  • Spells（法術）：可直接放到角色卡上。

尋找內容：側邊欄

左側欄位（1）可以篩選你目前所在分頁的內容。陣營、稀有度、生物類型、生態、來源（Patreon、免費、商店）。在地圖分頁還有 4K 或 HD 切換開關（2），配備較輕量的機器請選 HD（原因見此）。清單或格狀檢視可依喜好切換。

開啟與安裝

點擊任何搜尋結果，會滑出一個抽屜面板（1），內含描述、預覽和安裝按鈕（2）（完整流程見安裝內容）。趕時間？直接把地圖、生物或物品拖到畫布或 Actors 側邊欄即可。

保持整潔

  • 有可用更新：你擁有的內容若有較新版本，會顯示徽章。重新安裝即可更新，不需要先移除任何東西。
  • 孤立內容清理：維護工具會清除失聯的 Actor 和物品，讓你的側邊欄保持乾淨。

鎖定的內容

視窗會顯示完整目錄，包括你的會員資格尚未涵蓋的部分。鎖定的內容會標示加入提示，讓你隨時看得到加入會員能多獲得什麼。想解鎖，請先登入；想瞭解各階級提供的內容，請閱讀 Patreon 階級與商店。

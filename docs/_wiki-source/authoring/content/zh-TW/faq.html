新手上路

Beneos 到底是什麼？

為桌上角色扮演遊戲準備的動畫戰鬥地圖與完整備妥的遊戲內容。地圖是動畫影片；生物、法術與戰利品是靜態美術，但已經準備好直接開玩，附有傳說、自動化與可列印卡片。整體概覽請見歡迎頁面。

我需要什麼才能使用？

一個會員資格（Patreon）或一次性的商店購買、一個在 beneos-battlemaps.com 上與之連結的免費 Beneos 帳號，還有，如果你在 Foundry 中遊玩，免費的 Beneos 模組。就這樣。請見必要模組與設定。

我需要 Foundry VTT 嗎？

不需要。你有三種遊玩方式：在 Foundry VTT 中（最深入、一鍵完成的體驗）、在 Roll20 或 Alchemy 等任何其他 VTT 中直接使用檔案，或在桌邊用任何影片播放器搭配電視遊玩。Foundry 是可選的。

我必須購買 Foundry VTT 嗎？

只有想要 Foundry 體驗時才需要。Foundry 是向其開發者一次性買斷的，不是訂閱制。如果你使用託管服務，就在那裡輸入你的 Foundry 授權金鑰。實體桌遊或其他 VTT 都不需要 Foundry。

有沒有最新的設定指南？

有。從模組內的 Getting Started 教學和快速入門影片開始。如果你在網路上找到看起來過時的舊指南，請改用 Beneos 網站連結的最新版本。

我對 Foundry 非常陌生。要怎麼使用這些東西？

關於 Foundry 的一般問題，網路上眾多的入門影片是很好的起點。任何 Beneos 專屬的問題，下一站是我們的 Discord，而快速入門會帶你踏出使用模組的第一步。

真的像看起來那麼簡單嗎？

只有設定這一步需要花點時間。在 Foundry 中就是一次點擊，屬於一張地圖的一切（牆壁、光照、音效、日誌、傳送點）都會一併帶上。

Patreon、階層與價格

Battlemaps 和 Creatures 是兩個不同的東西嗎？

是的。Beneos Battlemaps 和 Beneos Creatures, Spells & Loot 是兩個獨立的會員資格，其中一個不包含另一個。請見 Patreon 階層與商店。

我該選哪個 Battlemaps 階層？

Tier 1（Tableplay）提供 4K 與 HD 的地圖檔案，供實體桌遊或任何 VTT 使用。Tier 2（FoundryVTT）額外加上一鍵完成的 Foundry 整合，也是最受歡迎的。完整比較請見階層頁面。

Battlemaps 階層有包含生物或法術嗎？

沒有。生物、法術與戰利品是獨立的會員資格，也就是 Beneos Creatures, Spells & Loot 上的 All Unit 階層。

為什麼實際階層比 Patreon 頁面顯示的多？

多年來，隨著價格或內容調整，有些階層被替換並隱藏。停留在舊隱藏階層的贊助者保有他們的存取權；新成員從今天顯示的階層中選擇。

你們有打折活動嗎？

有，不定期舉辦。請留意 Patreon 和我們的公告。

我可以為我的社群拿到創作者或聯盟折扣碼嗎？

請在 Discord 上聯絡團隊討論。

Discord 權限和 Patreon 綁在一起嗎？

在你的 Discord 設定中連結 Patreon，即可取得會員身分組。你的內容存取權本身是透過 Beneos 帳號與雲端運作的，不是透過 Discord。請見帳號連結。

你的 Beneos 帳號與存取權

我在哪裡註冊，帳號在哪裡？

一切都透過 beneos-battlemaps.com 運作。你的帳號、Patreon 連結和下載內容都放在那裡的你的媒體庫。舊的 beneos.cloud 網址現在只會轉址到那裡，所以不需要再記另一個網站。

如何建立帳號並連結 Patreon？

兩種方式。你可以在 beneos-battlemaps.com 上註冊，或直接在 Foundry 內的 Beneos 模組中輸入你的電子郵件：它會自動建立帳號，並寄給你一組登入代碼。接著到網路商店的帳號區連結你的 Patreon。請見登入與帳號。

Beneos 和 Patreon 一定要用同一個電子郵件嗎？

用同一個最省事，但不是必須。在你的帳號區把 Patreon 連結到 Beneos 帳號後，你的 Patreon 電子郵件會被儲存為第二個地址。所以就算你當初用了不同的電子郵件註冊（不論是刻意還是不小心），連結 Patreon 就能把一切正確地串起來。請見帳號連結。

Foundry 模組的登入資訊在哪裡？

就是你的 Beneos 帳號，也就是你註冊時用的電子郵件，不是你的 Patreon 密碼。你用寄到該信箱的一次性代碼登入。帳號管理在 beneos-battlemaps.com 的「你的媒體庫」中進行。

我是贊助者，但內容顯示為鎖定。為什麼？

幾乎都是帳號連結問題。到你的帳號區確認 Patreon 已連結且訂閱是有效的。如果你用了和 Patreon 不同的電子郵件，請確認 Patreon 連結已完成，因為正是它把兩邊綁在一起。全新的會員資格也可能需要幾分鐘，因為 Patreon 大約每 20 分鐘同步一次。

我沒收到確認信或登入信。

檢查你的垃圾郵件資料夾，確認電子郵件沒填錯，然後等幾分鐘。如果還是沒收到，在 Discord 上詢問或開一張支援單，我們會協助你。

下載與安裝

我在哪裡瀏覽與安裝內容？

一切都在 Foundry 內的 Beneos 雲端視窗中，背後由你的媒體庫支撐。在那裡瀏覽，然後安裝你需要的內容。牆壁、光照、音效和日誌會隨每張地圖一起送達。請見雲端視窗與安裝內容。

「全部匯入」和「更新」有什麼差別？

「全部匯入」把內容從雲端帶進你的世界供你使用。「更新」把你已擁有的內容刷新到最新版本。有新版本時，其列表會顯示更新徽章。

我還需要 Moulinette 或 Scene Packer 模組嗎？

不需要。目前的方式是模組內建的原生 Beneos 雲端安裝器。在過渡期間 Moulinette 仍可作為舊有途徑使用，但已不再是必需。

可以一次安裝整個戰役嗎？

目前你以單一發行版本或組合包的方式安裝。一鍵安裝整個戰役的按鈕還沒有，主要是因為資料量非常龐大。

可以只下載 HD、跳過 4K 嗎？

每個發行版本都同時提供 4K 與 HD。HD 是給較弱機器的輕量選項。安裝時用 4K / HD 切換鈕為每張地圖選擇解析度。請見效能與品質。

不用 Foundry 要怎麼下載？

每個階層在 beneos-battlemaps.com 的你的媒體庫中都有下載區，你可以直接以 ZIP 形式取得檔案，完全不需要 Foundry。

雲端視窗打不開。

按 F12 開啟主控台，點擊 Console，再點 Errors，看看按下按鈕時是否出現錯誤。有的話請在 Discord 上回報，我們會處理。雲端後端託管在線上，所以它保持最新，我們也能在不更新模組的情況下推送修正。另外請確認你已登入。

我匯入了內容，卻出現黑畫面或顯眼的驚嘆號。

這通常表示下載逾時或發生錯誤，導致 Foundry 找不到某個檔案（地圖背景、講義或圖示）。從場景與日誌側邊欄刪除受影響的場景及其講義，然後重新安裝該內容。如果持續發生，請在 Discord 上回報，我們會和你一起排查。請見安裝內容。

地圖

戰鬥地圖發行版本附帶什麼？

動畫戰鬥地圖及其場景畫面（4K 與 HD）、一段電影感開場動畫、環境音訊、靜態圖片，以及講義。在 Foundry 中，牆壁、光照與興趣點導航都已設定完成。請見動畫戰鬥地圖。

地圖是什麼檔案格式？

動畫影片：Foundry 內為 WebM，下載檔案為 MP4。靜態圖片為 WebP 與 PNG。

4K 和 HD 有什麼差別？

解析度與檔案大小。4K 是最高品質；HD 較小、對效能較友善。每個發行版本都同時提供兩者。

地圖有附日誌或 DM 筆記嗎？

發行版本在適用時會附帶講義與日誌內容。具體內容因發行版本而異。

場景之間的導航是怎麼運作的？

Beneos 地圖使用興趣點傳送點：從總覽或世界地圖跳進各個場景，安裝後這些連結已為你設定好。請見 Point of Interest Teleporter 與 DM 導航。

Point of Interest Teleporter 也能用在非 Beneos 的地圖上嗎？

可以，傳送點是通用工具，不限於 Beneos 地圖。你可以把它加到自己的場景上。

我可以對玩家隱藏興趣點或標記嗎？

可以，使用 Foundry 針對該場景的可見性與筆記權限設定即可。

我可以許願特定的地圖嗎？

歡迎在 Discord 上提出地圖建議。我們無法保證做出特定某一張，但社群意見會影響我們的規劃。

生物、法術與戰利品

生物、法術與戰利品是動畫的嗎？

不是。只有地圖、場景畫面與開場動畫是動畫的。生物、法術與戰利品是靜態美術，但都已為遊戲完整準備好。

新的生物、法術與物品多久推出一次？

大約每兩週一隻新生物、每月一批法術，以及每月一次魔法物品。

每隻生物附帶什麼？

一個 2.5D Token 和一個 Top-Down Token，一鍵切換，附一個或多個變體，還有一份 Codex：傳說、任務鉤子、伏筆線索、登場與死亡的可朗讀文字，以及一份戰術指南。另外還有 Combat Autopilot 能替你操作生物的回合。請見 Creature Codex。

如何在 2.5D 與 Top-Down Token 之間切換？

在畫布上對 Token 按右鍵，選擇另一種樣式。你也可以在瀏覽器中為每隻生物設定預設樣式。

生物、法術與戰利品只適用於 D&D 5e 嗎？

它們的數據方塊與自動化是專為 D&D 5e 設計的。美術素材仍可用於其他系統。針對 Pathfinder Second Edition，我們把每隻生物發布在預設角色卡上，讓你至少能使用圖片；目前還沒有 D&D 到 Pathfinder 的轉換器。

我可以把生物、法術與戰利品印出來給我的桌用嗎？

可以。每隻生物、每件物品與每個法術都附有可列印 PDF，可線上取得，或在 Foundry 中透過 Creature Codex 的按鈕直接開啟。此外，每個法術與物品都有一張自訂 Beneos 設計的可列印交換卡，讓你能把實體的戰利品卡與法術卡交到玩家手上。卡片版型收錄在各 PDF 中，在 Foundry 內也會直接以卡片形式呈現。

SRD 內容是免費的嗎？

不是。完整的 5e SRD 生物、法術與物品庫是付費的 Creatures, Spells & Loot 會員資格的一部分，與 Beneos 原創內容並列。

戰利品特別在哪裡？

每件物品都有一個 Origin，也就是主題。相同 Origin 的物品共享加成，契合多件可獲得最多三件的套裝加成。集滿三件後可以進行儀式吸收它們的力量。玩家也能透過遊戲內的物品雷達感應附近與自己契合 Origin 相同的物品。請見物品與 Origins。

模組可以幫我生成戰利品或商店嗎？

可以。戰利品產生器會為指定規模擲出符合等級的寶藏，而商店產生器能從鐵匠、煉金術士或黑市等原型建立一間標好價格的商店，使用 SRD 與 Beneos 物品。

為什麼有些生物或物品顯示為無法取得？

它們通常是每月的忠誠內容（見下方），或是帳號連結問題。如果商店裡列出的東西在雲端顯示為無法取得，可以在商店購買。

我錯過的舊忠誠生物還拿得到嗎？

每月初推出的額外生物是免費送給當月活躍贊助者的，不會加入標準內容庫。如果你當時不是贊助者，可以在商店購買。

在地圖上

場景畫面占滿整個螢幕，而且我不能移動。是錯誤嗎？

不是。場景畫面本來就是為角色扮演時刻設計的電影感全幅畫面，不是戰術地圖，所以上面沒有東西可移動。用場景上的戰鬥地圖傳送點跳回戰術版本。DM 導航有各圖示的說明。

日誌傳送點把我送到錯誤的場景。

那個日誌圖示很可能沒有指定目標日誌，或者同一個日誌被指定給了多個場景。你可以手動重新連結，也希望你在 Discord 上簡短回報一下，讓我們能為所有人修正。逐步修復方法請見 Point of Interest Teleporter。

我的玩家 Token 被傳送到隨機或錯誤的位置。

這指向某個傳送區域的目的地識別碼有誤。應該恰好有兩個傳送點共用同一個 Teleport Identifier。如果超過兩個，會隨機選擇一個；如果一個都沒有，就不會有任何動作。請見 Multilevel Tokens，並請在 Discord 上回報有問題的傳送點。

我的生物和 Token 消失在樹木或牆壁下面。怎麼回事？

這是刻意設計的。我們把所有比玩家高的東西裁切出來，作為前景圖片疊放在 Token 上方，讓地圖擁有真實的深度感。這些是前景（頭頂）圖塊。要編輯它們，開啟圖塊控制，先點擊房子圖示。完整說明請見前景圖塊深入解析。

有些地圖上有鳥、霧或雨。可以關掉嗎？

許多效果是直接烘焙進影片裡的，無法更改。有些場景還使用 FXMaster 模組提供額外的濾鏡與粒子效果。要移除那些效果，開啟左側的魔杖工具列，使用小垃圾桶圖示清除場景上的所有效果。請見 FXMaster 深入解析。

為什麼我的開場動畫沒有播放？

開場動畫可循環播放且預設為暫停，因為玩家常常在不同時間進入場景。等所有玩家到齊後，DM 點擊導航底部的開始與暫停圖塊，為所有人啟動開場動畫。請確認 Monks Active Tile Trigger 模組已安裝並啟用。請見 Monks Active Tile Trigger 深入解析。

地圖上有很多聲音。它們從哪裡來，音量怎麼調？

音訊是以環境音效的形式放在音效圖層上的，你可以從左側控制選單進入，在那裡調整音量、靜音或移除音效。每位玩家和 DM 也各自設定自己的音量：播放清單滑桿控制 DM 音樂，環境音滑桿控制地圖音效與序列，介面滑桿控制門的音效。請見環境氛圍與音效。

在 Foundry 之外使用 Beneos

沒有 VTT 的實體桌遊能拿到什麼？

4K 與 HD 的 MP4 動畫戰鬥地圖與場景畫面、所有靜態圖片、環境音軌、講義，以及開場序列。用任何影片播放器在電視上播放即可。

可以在 Roll20 等其他 VTT 中使用 Beneos 嗎？

可以。任何支援動畫影片或圖片檔案的 VTT 都能使用 Beneos 內容，例如 Roll20、Owlbear Rodeo、Fantasy Grounds 或 Alchemy RPG。那裡沒有一鍵安裝：你需要手動上傳並準備檔案，所以體驗較為有限。想要完整的一鍵體驗，我們推薦 Foundry VTT。

戰役內容與相容性

你們有 Curse of Strahd 或 Descent into Avernus 嗎？

我們製作與熱門出版戰役相容的內容。Curse of Strahd 已大致完成，還包含一些自創地點，而我們目前的重心是與 Descent into Avernus 相容的內容。

我匯入了出版冒險的場景。冒險文字在哪裡？

由於版權因素，我們無法收錄 Wizards of the Coast 的冒險文字。如果你在 D&D Beyond 上擁有該冒險，可以使用 D&D Beyond Importer 這類模組合法地把文字匯入你的世界。

還會有更多與戰役相容的內容嗎？

會。大約每兩個發行版本就有一個與我們當前聚焦的戰役相容，內容庫也持續擴充中。

地圖上的「尚未推出」標籤是什麼意思？

它標記一個屬於該戰役系列、但我們還沒發行的地點。它正在路上，這個標籤讓你看到系列中的缺口，知道它即將到來。

這些地圖能搭配改編版或第三方版本的戰役使用嗎？

可以。地圖不綁定特定規則集，改編或自創版本都能使用。

版本、扣款與取消

我需要哪個 Foundry 與系統版本？

Foundry V14（V13 仍受支援）、dnd5e 系統，以及最新的 Beneos 模組。請見必要模組與設定。

我應該升級到 Foundry V14 嗎？

只有在你需要 V14 功能時才需要。就 Beneos 內容而言，V14 完全受支援，但不比 V13 更好，所以不用著急。

戰鬥地圖綁定特定遊戲系統嗎？

不會，地圖與系統無關，任何系統都能使用。只有生物、法術與戰利品是專為 D&D 5e 打造的，不過它們的美術素材仍可用於其他系統。

取消後我的內容還在嗎？

已安裝到你世界裡的東西會保留，不會被刪除。只是會員資格結束後，你無法再下載新檔案。在商店購買的內容則永遠可以下載。

哪裡可以獲得協助？

Beneos Discord 是最好的地方。先搜尋 FAQ 與疑難排解頻道，如果還是解決不了，就在支援頻道開一張支援單，團隊會協助你。邀請連結在錯誤回報與聯絡方式頁面上。

Beneos는 두 개의 Patreon과 하나의 상점으로 운영돼요. 어느 것이 맞는지는 딱 하나에 달려 있어요: 여러분이 실제로 어떻게 플레이하는지예요. 전체 그림을 짧게 정리했어요.

Beneos Battlemaps: 두 개의 티어, 두 가지 플레이 방식

이 Patreon에는 별개의 티어 두 개가 있어요. 누적되는 구조가 아니에요. 여러분의 테이블에 맞는 것을 고르세요.

티어받는 것이런 경우에 선택
Tier 1, Tableplay고해상도 비디오(MP4)로 제공되는 맵실물 테이블에서 플레이하거나, Foundry가 아닌 VTT를 사용해요
Tier 2, FoundryVTT완성된 애니메이션 Foundry 씬, 클릭 한 번이면 월드에 들어와요Foundry VTT에서 게임을 진행해요

Foundry를 쓰나요? 그럼 Tier 2예요. 씬 전체가 완성된 채로 도착해요: 벽, 조명, 사운드, 텔레포터까지 전부요. Tier 1은 대신 맵 원본 비디오를 제공하는데, 테이블 위의 TV나 다른 VTT에서 쓸 때 원하는 형태예요.

Beneos Creatures, Spells & Loot: All Unit 티어

Patreon 하나, 티어 하나예요. All Unit 티어는 이쪽에서 만드는 모든 것을 잠금 해제해요: 모든 크리처, 모든 주문, 모든 아이템. Cloud 창에서 Foundry로 바로 설치할 수 있고, 코덱스 페이지, Origin 등이 함께 제공돼요.

Beneos 상점

멤버십 없이 릴리스 하나만 원하나요? Beneos 상점에서는 맵이나 크리처 하나를 구매해서 영구 소장할 수 있어요. 아직 준비 중이니, 당분간은 메인이 아니라 두 번째 문으로 생각해 주세요.

무료

무료 Beneos 계정만으로도 이미 모든 종류의 무료 콘텐츠를 받아요: 무료 맵, 크리처, 전리품, 주문에 정지 이미지까지. 비용이 전혀 들지 않고, Beneos가 여러분의 테이블에 맞는지 확인하는 가장 쉬운 방법이에요.

웹숍 라이브러리에서는 각 릴리스가 두 가지 다운로드를 나란히 제공해요: Tableplay 비디오(1)와 Foundry 씬(2)이에요.

실제로 받는 방법

Foundry 안에서 Beneos Cloud 창을 열고 소유한 것을 설치하세요. 파일로 직접 받고 싶나요? 웹숍 라이브러리에서 ZIP을 다운로드하세요. 어느 쪽이든 접근 권한이 인식되도록 계정이 연결되어 있는지 확인하세요.

다운로드 링크는 계정에 묶여 있어요. 공유하지 마세요, 링크에는 여러분의 이름과 접근 권한이 담겨 있어요.

Beneos Cloud 창은 Beneos의 모든 것(크리처, 전리품, 주문, 맵)을 둘러보고, 미리 보고, 설치하는 단 하나의 장소예요. 상점이자 설치 도구인데, Foundry를 벗어날 필요가 전혀 없어요. 설치한 것은 곧바로 여러분의 월드에 들어와요.

열기

Foundry 왼쪽 도구 모음(캔버스의 세로 스트립)에서 Beneos 아이콘(1)을 클릭하세요. 작업하는 동안 창을 열어 두고 필요한 것들을 그때그때 끌어다 놓으면 돼요.

탭

창 상단에 다섯 개의 탭(1)이 나란히 있어요:

  • Home: 소식, 패치 로그, 그리고 로그인하는 곳이에요.
  • Creatures: 2.5D와 Top-Down 토큰이에요, 각각 액터와 코덱스 페이지가 함께 제공돼요.
  • Maps: 애니메이션이 적용되고 완전히 구성된 배틀맵 씬이에요.
  • Loot: 아이템과 장비예요, Origin이 함께 제공돼요.
  • Spells: 시트에 바로 끌어다 놓을 수 있어요.

찾기: 사이드바

왼쪽 레일(1)은 현재 보고 있는 탭을 필터링해요. 세력, 희귀도, 크리처 유형, 생물군계, 출처(Patreon, Free, Shop)로요. 맵에서는 4K 또는 HD 스위치(2)도 여기에 있어요, 사양이 낮은 기기라면 HD를 고르세요(이유). 목록과 그리드 보기는 취향대로 전환하면 돼요.

열고 설치하기

결과를 클릭하면 설명, 미리보기, Install(2)이 담긴 드로어가 옆으로 열려요(1)(전체 과정은 콘텐츠 설치에 있어요). 바쁘신가요? 맵, 크리처, 아이템을 캔버스나 액터 사이드바에 바로 끌어다 놓으세요.

깔끔하게 유지하기

  • 업데이트 알림: 소유한 항목에 새 버전이 나오면 배지가 표시돼요. 다시 설치하면 업데이트되고, 미리 제거할 것은 없어요.
  • 고아 항목 정리: 유지 관리 도구가 연결이 끊긴 액터와 아이템을 정리해서 사이드바를 깨끗하게 유지해 줘요.

잠긴 콘텐츠

이 창은 멤버십이 아직 포함하지 않는 것까지 전체 카탈로그를 보여줘요. 잠긴 콘텐츠에는 Join 안내가 표시되기 때문에, 멤버십으로 무엇이 추가되는지 항상 볼 수 있어요. 잠금을 해제하려면 로그인하세요. 각 티어가 무엇을 주는지는 Patreon 티어와 상점을 읽어 보세요.

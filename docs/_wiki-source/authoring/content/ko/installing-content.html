설치는 클릭 한 번이에요. 에셋을 고르고, 확인하면, 여러분의 월드에 들어와 연결까지 끝난 상태로 준비돼요. 먼저 로그인해서 모듈이 여러분의 소유 콘텐츠를 알 수 있게 하세요.

Install 클릭

Cloud 창에서 에셋을 찾아 Install을 누르세요. 맵은 Maps 탭 상단의 4K / HD 스위치로 먼저 해상도를 설정하고, 크리처, 전리품, 주문은 항상 최고 품질로 설치돼요. 작성할 양식은 없어요. 모듈이 백그라운드에서 접근 권한을 확인하고(잠긴 콘텐츠는 설치 대신 Join 안내를 표시해요), 이미 소유한 것은 건너뛰고, 곧바로 다운로드를 시작해요. 진행 창이 처음부터 끝까지 추적하고, 이미 가진 것을 다시 설치할 때는 씬을 덮어쓰기 전에 먼저 물어봐요.

월드에 들어오는 것

크리처, 전리품, 주문은 내려받아져 월드의 beneos_assets 폴더에 풀립니다. 맵도 장면, 정지 이미지, 저널, 토큰을 그곳에 두지만, 영상과 소리는 저희 서버에 남아 플레이하는 동안 전달됩니다. 어느 쪽이든 모듈이 그다음에 연결해 줍니다.

  • 크리처는 2.5D와 Top-Down 토큰을 갖춘 액터(1)가 되어 사이드바에 들어와요.
  • 전리품과 주문은 시트에 끌어다 놓을 수 있는 아이템이 돼요.

디스크에 있어야 할 것은 설치 뒤에 검사되므로 반쯤 설치된 액터가 남는 일은 없습니다. 스트리밍되는 영상은 이 검사에 포함되지 않습니다. 애초에 디스크에 남을 것이 아니기 때문입니다. 파일이 빠져 있으면 모듈이 짐작하게 두지 않고 알려 줍니다.

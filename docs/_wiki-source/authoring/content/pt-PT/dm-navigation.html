A funcionalidade que distingue os Beneos Battlemaps é os mapas estarem ligados entre si. A maioria das releases junta vários mapas de um mesmo local, todos ligados a um mapa geral. Como Mestre, saltas de um mapa para a sua scenery, ou recuas para o mapa geral para uma vista de pássaro. O módulo Point of Interest Teleporter trata disto, e nós deixamos tudo configurado de antemão. Esta página cobre apenas as interações. Queres construir as tuas próprias ligações? Há um mergulho técnico opcional em POI Teleporter.

Nota: todos os ícones aqui são invisíveis para os jogadores. Existem para o Mestre, para a navegação funcionar sem qualquer conhecimento técnico.

Clique direito para viajar

Os mapas trazem entradas de journal colocadas. Clica com o botão direito numa delas e tens duas opções de Mestre:

  • View Scene muda apenas o Mestre para a cena de destino.
  • Activate Scene move todos os jogadores ativos para a cena de destino.

Tornar os ícones visíveis

Não há ícones de journal nos teus mapas? Ativa-os. Na barra de ferramentas do Foundry à esquerda, clica no ícone de bandeira (notas) e depois no ícone de pin chamado Toggle Notes Display. Todos os ícones de journal ficam visíveis.

O que significam os ícones

Todas as releases Beneos usam o mesmo ícone para a mesma função. Aprende-os uma vez e todos os mapas se leem da mesma forma.

ÍconeSignificado
Mapa geral. Leva ao mapa geral principal do pack.
Mapa regional. Destaca a região ou reino específico dentro do mundo de fantasia da Beneos, Escalia. Dá contexto, seja um reino ou um lugar como Barovia.
Mapa do mundo. Uma porta de regresso ao mapa global, com saltos para continentes ou reinos. Este mapa usa o Monk's Active Tile Triggers, por isso mantém todos os módulos necessários ativos.
Handouts opcionais para jogadores. Duplo clique para uma imagem imersiva do mapa atual. Opcional, e bom para destacar aspetos relevantes para a história.
Scenery. Uma vista imersiva e cinematográfica do battlemap atual, ideal para momentos de interpretação.
Battlemap. A vista tática da scenery atual, para combate ou exploração mais profunda.
Ajuda. Liga de volta a este guia.
Intro para jogadores. Sequências de vídeo produzidas especialmente para uma introdução imersiva a uma cena, quando disponíveis.
Bússola. Ajuda-te a orientar em battlemaps e sceneries, sobretudo quando as sceneries mostram perspetivas diferentes.
Navegador do Mestre. Colocado nas margens dos battlemaps para apontar para a cena de destino, dando-te sentido de direção.
Informação. Alguns mapas acrescentam dicas ou informação para o Mestre, sempre no canto superior esquerdo.

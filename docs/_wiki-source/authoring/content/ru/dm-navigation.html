Главная особенность Beneos Battlemaps в том, что карты связаны между собой. В большинстве релизов несколько карт собраны для одного места, и все они привязаны к обзорной карте. Как ГМ вы переходите с карты на её Scenery или возвращаетесь к обзорной карте, чтобы взглянуть на место сверху. Этим занимается модуль Point of Interest Teleporter, и мы всё настраиваем заранее. Эта страница описывает только взаимодействия. Хотите создать собственные связи? Для этого есть необязательный разбор в разделе POI Teleporter.

Примечание: все значки здесь невидимы для игроков. Они существуют для ГМа, чтобы навигация работала без технических знаний.

Перемещение по правому щелчку

На картах лежат размещённые записи журнала. Щёлкните правой кнопкой по одной из них, и вы получите два варианта для ГМа:

  • View Scene переключает только ГМа на целевую сцену.
  • Activate Scene переводит всех активных игроков на целевую сцену.

Сделать значки видимыми

Нет значков журнала на картах? Включите их. На панели инструментов Foundry слева нажмите значок с флажком (заметки), затем значок-булавку с подписью Toggle Notes Display. Все значки журнала останутся видимыми.

Что означают значки

Каждый релиз Beneos использует один и тот же значок для одной и той же задачи. Выучите их один раз, и каждая карта будет читаться одинаково.

ЗначокЗначение
Обзорная карта. Ведёт на главную обзорную карту пака.
Региональная карта. Выделяет конкретный регион или королевство в вымышленном мире Beneos, Escalia. Даёт контекст, будь то королевство или место вроде Баровии.
Карта мира. Шлюз обратно к глобальной карте с переходами к континентам или королевствам. Эта карта использует Monks Active Tiles, поэтому держите все нужные модули включёнными.
Необязательные раздаточные материалы для игроков. Двойной щелчок открывает погружающий кадр текущей карты. Необязательно, но удобно для выделения важных для сюжета деталей.
Scenery. Погружающий, кинематографичный вид текущей боевой карты, идеально подходящий для ролевых моментов.
Боевая карта. Тактический вид текущей Scenery для боя или более глубокого исследования.
Помощь. Ссылка обратно на это руководство.
Вступление для игроков. Специально созданные видеосцены для погружающего начала сцены, где они доступны.
Компас. Помогает ориентироваться на боевых картах и Scenery, особенно когда Scenery показывают разные ракурсы.
Навигатор ГМа. Размещается по краям боевых карт и указывает на целевую сцену, давая представление о направлении.
Info. На некоторых картах в левом верхнем углу есть подсказки или сведения для ГМа.

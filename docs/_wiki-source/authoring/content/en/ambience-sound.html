Beneos maps come with sound built in: ambient soundscapes, intro audio, click effects on interactive features, and door sounds. Animated maps run looping ambience playlists that start with the scene, so the atmosphere is there the moment you open a map. This page is about controlling the volume.

Where to set the volume

Simple, with one catch: you cannot set the volume for your players. Each player adjusts it on their own client. Volume lives in the Playlist tab in the top-right navigation bar.

  • The Playlist slider sets the DM's music, meaning everything played in the Playlist tab.
  • The Ambient slider is the important one. It controls intros, map sounds, and the click effects on interactive maps.
  • The Interface slider sets door sounds. If doors feel too loud, turn it down.

Because each client sets its own levels, if a player says the music is too loud or quiet, point them to their own Playlist sliders. There is no central volume the DM can push to everyone.

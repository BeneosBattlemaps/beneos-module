Installing is a click. Pick an asset, confirm, and it is in your world, wired up and ready. Sign in first so the module knows what is yours.

Click Install

In the Cloud window, find the asset and hit Install. For maps, set the resolution first with the 4K / HD switch at the top of the Maps tab; creatures, loot and spells install at full quality. There is no form to fill in. The module checks your access in the background (locked content shows a Join prompt instead of installing), skips anything you already own, and goes straight to the download. A progress window tracks it from start to finish, and reinstalling something you already have asks first before it overwrites the scenes.

What lands in your world

The asset downloads and unpacks into your world's beneos_assets folder, then the module hooks it up:

  • Creatures become an Actor (1) in your sidebar, with their 2.5D and top-down tokens.
  • Loot and spells become Items you can drag onto a sheet.

Everything is checked on disk afterwards, so you never get a half-installed actor. If a file is missing, the module says so instead of leaving you guessing.

Updates

When we ship a newer version, its listing shows an Update available badge. Reinstall and the new version replaces the old one in place.

The standout feature of Beneos Battlemaps is that the maps are connected. Most releases bundle several maps for one location, all tied to an overview map. As DM you jump from a map to its scenery, or pull back to the overview for a bird's-eye view. The Point of Interest Teleporter module handles this, and we set it all up in advance. This page just covers the interactions. Want to build your own links? There is an optional deep dive in POI Teleporter.

Note: every icon here is invisible to players. They exist for the DM, to make navigation work without any technical know-how.

Right-click to travel

Maps carry placed journal entries. Right-click one and you get two DM options:

  • View Scene switches only the DM to the target scene.
  • Activate Scene moves all active players to the target scene.

Make icons visible

No journal icons on your maps? Turn them on. In the Foundry toolbar on the left, click the banner (notes) icon, then the pinhead icon labeled Toggle Notes Display. All journal icons stay visible.

What the icons mean

Every Beneos release uses the same icon for the same job. Learn them once and every map reads the same way.

IconMeaning
Overview map. Leads to the pack's main overview map.
Regional map. Highlights the specific region or kingdom within Beneos' fantasy world, Escalia. Gives context, whether it is a kingdom or a place like Barovia.
World map. A gateway back to the global map, with jumps to continents or kingdoms. This map uses Monks Active Tiles, so keep all required modules active.
Optional player handouts. Double-click for an immersive shot of the current map. Optional, and good for highlighting story-relevant aspects.
Scenery. An immersive, cinematic view of the current battlemap, ideal for role-playing moments.
Battlemap. The tactical view of the current scenery, for combat or deeper exploration.
Help. Links back to this guide.
Player intro. Specially produced video sequences for an immersive intro to a scene, where available.
Compass. Helps you orientate on battlemaps and sceneries, especially when sceneries offer different perspectives.
DM navigator. Placed on the edges of battlemaps to point toward the target scene, giving you a sense of direction.
Info. Some maps add tips or information for the DM, always in the top-left corner.

Before you read: none of this is needed to use Beneos Battlemaps. Everything is set up for you and works out of the box. This deep dive is for anyone who wants to add Monks Active Tile Trigger functions to their own maps, or is just curious how it works.

Monks Active Tile Trigger (MATT for short) is one of the most powerful automation modules for Foundry VTT. It is a companion module, not part of the Beneos Module, so make sure it is installed and active. See Requirements for the full list.

What we use MATT for

MATT is an all-rounder for automating or controlling parts of a scene. We use it for:

  • Start and stop buttons that play and pause the player intro sequences.
  • Click-based navigation on the Escalia world map.
  • Mini soundboards on some scenes (for example Barovia Village, The Church).
  • Placed buttons for traps, secret doors, or other clickable events.
  • The navigation bar for the Curse of Strahd main menu.

MATT can start animations, play sounds, jump to scenes, and much more. Covering every function here would be overwhelming, and a wiki page is the wrong format for it. To go deep, there are excellent video tutorials online. Below we walk through how we use MATT so you can build your own ideas on top.

How MATT works

Everything in MATT works through tiles. The Tile Configuration gains a new tab called Triggers. MATT runs on cause and effect: when a trigger defined in Setup is met (a click, a token entering the tile, or many other conditions), whatever is defined in Actions happens.

In this example a tile is the start and stop button for the intro sequences. The intro is also a tile, and it only plays when you click the play button tile.

Select Tile Controls in the left toolbar to click tiles on the canvas. Clicking our play button (a tile with a play-button image) lets us define under Triggers what should happen and when.

In Setup you define when the action runs. Here the tile only triggers when the GM clicks it.

Under Actions, several actions are chained to a single click. MATT runs them top to bottom. Here: the tile holding the intro is reset so it starts from the beginning (Foundry has a quirk of starting webm videos at random positions), then the intro tile is started, then the clicked tile's image is swapped so the play button turns red and reads as a stop button next time, and finally a click sound plays as feedback for all players and the DM. The swap images are defined in the Images tab.

The Images tab collects the images MATT switches between. Here just two, start and stop, swapped each click. A technical note: the two images live under different file paths. When we pack a release, the second image is not exported and would be missing on download. So the second image ships inside the Beneos Module itself, which is always installed and therefore always available.

That was one example. To build your own ideas, inspect the tiles we use to control intros, build soundboards, or trigger traps. With a little creativity you can make genuinely cool interactive effects. Foreground tiles can carry MATT triggers too, covered in our foreground tiles deep dive.

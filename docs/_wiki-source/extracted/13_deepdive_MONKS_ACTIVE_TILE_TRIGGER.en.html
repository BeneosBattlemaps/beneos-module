Before You Read

Here you'll find additional information that is not needed for using Beneos Battlemaps. All the sensible functions and settings have already been done for you in advance, and you can use everything immediately and intuitively. This deep dive is meant for those who want to add MATT functions to their own maps or are just curious about how the module works.

Why Monks Active Tile Trigger (MATT)?

For those familiar with the module, the question doesn't even arise. MATT is one of the most modern, powerful, and versatile modules available for Foundry. It's an all-rounder offering numerous ways to automate or control game aspects. Beneos uses MATT for functions like:

  • Start/Stop buttons for playing and pausing Player Intros
  • Click-based navigation on the Escalia World Map
  • Mini soundboards on some scenes (e.g., Barovia Village - The Church)
  • Placed buttons for traps, secret doors, or other clickable events on the map
  • Navigation bar for the Curse of Strahd main menu

With MATT, you can start animations, play sounds, navigate to scenes, and much more. Covering all functions and combinations here would be insane, and text isn't well-suited for this, especially not in a journal. I suggest looking up more about it on YouTube if interested. There are some very good tutorials. Next, I'll go over the implementation of Beneos features.

How Does MATT Work?

As the name suggests, everything in Monks Active Tile Trigger works through Tiles. In the Tile Configuration, there's a new tab called "Triggers." MATT operates on a cause-and-effect principle. That is, when a defined trigger in "Setup" is met (a click on the Tile, a Token entering the Tile, or various other conditions), then what's defined in "Actions" happens.

In this example, I use a Tile as a Start<->Stop button for the Intro sequences. The Intros themselves are also a Tile that only starts playing when you click on the Play button Tile.

When you select "Tile Controls" in the toolbar on the left side of the screen, you can click on Tiles on the Canvas. Now, clicking on my Play button, which is just a Tile with a Play button image, we can set under "Triggers" what and when something should happen.

In "Setup," the triggers are defined for when the action should be executed. In this case, the Tile is only triggered when the GM clicks on it.

Under Actions, you can see that I've defined several actions to be executed with one click. MATT works sequentially, starting from the top. From top to bottom, the following is done: 1 - The Tile with the Intro Sequence is reset so it starts from the beginning (Foundry has a quirk of starting webm videos at random positions). 2 - Then the Tile with the Intro Sequence is started. 3 - After that, the image of the Tile that was clicked is changed. This gives interactive feedback that the animation is running, and the Play Button turns red, symbolizing "Stop" for the next click. The images for this effect are defined in the "Images" tab. 4 - A sound file is played as additional user feedback. There's a click sound that all players and DMs can hear.

In the Images tab, as mentioned before, the images with which MATT can work are collected. I've only defined two here, one for Start and one for Stop, which switch on a click. Info: The images have different file paths for technical reasons. When I pack a release with Moulinette, the second image is not exported and therefore cannot be found when downloading. That's why the second image is part of the Beneos Module, which MUST always be installed and thus is always available to everyone.

This was just one example of how I use MATT. If you want to use MATT for your own ideas, check out the Tiles I use to control the intros, build the soundboard, or trigger traps. It's amazing what cool effects you can create with a bit of creativity.

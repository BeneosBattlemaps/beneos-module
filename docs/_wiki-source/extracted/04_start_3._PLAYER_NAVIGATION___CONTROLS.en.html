Not only DMs can move from one map to another. Players, or more precisely their character actors, can also move independently from one map to another. This is possible at specific points on the map and can be carried out by the player themselves. This functionality is primarily realized through the Foundry module "Multi Level Tokens". Ensure that the module is installed and activated in your world. The usage for players is super simple. If you want to understand more about the technology behind it or want to place your own MLT navigators, read through the MLT Deep Dive. But it's not necessary, as we've prepared everything for you.

MULTI LEVEL TOKENS

The MLT module connects two places with each other: an origin and a destination. It uses simple rectangle shapes, which can be found in the text toolbar on the left side. Within this rectangle shape, we've pre-configured the "address" to which this so-called Player Teleporter leads. On every Player Teleporter field, which only DMs can see, there's always a journal icon. As soon as a player clicks on one, their character token is "teleported" from the "origin" to the "destination", and the scene changes for that player alone. If the DM clicks on a journal icon in a teleporter zone, ALL tokens, whether player or non-player actors, are teleported. It's that simple.

As a DM, you're of course not obligated to let your players roam freely, but it can promote exciting and narratively gripping exploration. It's advisable for the DM to keep track of where each player is, and it's also a sign of respect if players announce beforehand that they're changing a scene, giving the DM the opportunity to properly describe the new location. There are two types of journal icons to control the teleporters.

If you want to learn more check the: DEEP DIVE: MLT TELEPORTER

Icon Meanings

PLAYER NAVIGATOR

  • This is the standard icon that all players see when they get close enough to it. Players CANNOT see this icon through walls; they must first reach the exit of the scene to interact with it. If a player clicks on the icon while a character they control is in the (invisible to the player) MLT zone, the character is teleported to the target scene, and the scene changes for that player alone.

HIDDEN DM NAVIGATOR

  • This icon does exactly the same thing as the Player Teleporter, with the difference that this icon is entirely invisible to players and cannot be used by them. It serves to use non-obvious paths, such as secret doors or other paths (to be discovered or opened later), to leave the scene. If the DM believes that the players can move on, the DM can click on the DM Navigator icon, and as with the Player Navigator, the players are teleported to the destination. This is great for traps, cleared paths, cracked doors, and so on.

Decide Which Journal Icons Players Can See on the Map

Players can only see the Journal Icon on the map that has been individually released to them or to all players. For example, if there are 5 Journal Icons placed on the map, but each Journal the icons refer to is only released to a specific player, then each player will only see the released one. This way, you can allow players to access their individual notes visible only to them, or separate DM navigation from player navigation.

To change the permission for a Journal, do it the same way as you would for a Token (= Actor). Go to the Journal Browser via "Journal" in the top-right navigation bar. Right-click on the Journal you want to release to one or more players and select "Configure Ownership." With "All Players," you can grant permission to all players created in the world (DMs are excluded). Below that, you can set individual rules for each player. Usually, you give the player who is supposed to have the sole right the permission and leave the others unchanged.

  • Owner: Grants the player(s) complete reading and editing rights.
  • Observer: Players can see the Journal but cannot edit it.
  • None: Players can neither edit nor see the Journal. This is the default setting for all DM navigation journals, like the Point of Interest Teleporter.

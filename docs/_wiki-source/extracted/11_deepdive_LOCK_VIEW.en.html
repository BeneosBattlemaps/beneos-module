Before You Read

Here you'll find additional information that is not needed for using Beneos Battlemaps. All the sensible functions and settings have already been done for you in advance, and you can use everything immediately and intuitively. This deep dive is meant for those who want to add Lock View functions to their own maps or are just curious about how the module works.

Why Lock View?

Lock View is a handy module that, as the name suggests, restricts the movement and zoom capabilities of users. For example, you can prevent users from zooming or moving the camera outside a certain area. For Beneos Battlemaps, we use this to prevent players from moving the camera outside the map/scenery, so they can't see the DM navigation bar or other elements not intended for players.

Why do we do this? For two important reasons. First, to prevent players from seeing elements not meant for them. Also, it's been very helpful for immersion to see the sceneries in full screen without being able to move around. This prevents casual clicking and helps players focus on the role-play scene, which is what the sceneries are made for.

Scene Configuration

How do we define a specific area? Each scene needs to be configured individually so that Lock View recognizes there's something to do. Each Scene Configuration has a new tab called "Lock View." Here, you select the "Bounding Box" checkbox, telling the module to look for a box configured for Lock View on this scene. With the "Force Initial View" box, you ensure that players always land within the field you defined and aren't "locked out."

Drawing Configuration

After configuring the scene, go to the scene and draw a rectangle using the "Drawing Tool" in the left toolbar. The appearance of the rectangle doesn't matter much, but I recommend something unobtrusive, as we never have to interact with this box again once it's set. Like the Scene Configuration, the configuration for the newly drawn rectangle has a new Lock View tab. There's only one setting option there. Under "Force to bounding box" in the Select Field, choose "Always" and click "Update Drawing." This tells the Lock View module to consider this particular drawing as the bounding box and limit player camera movement accordingly.

Lock View Settings & User/Scene Configuration

You can exempt all players from this limitation via the Lock View module settings if you don't need it. Normally, the DM of a world is always exempt from any limitations. But if you find yourself "trapped" in your bounding boxes, you can free yourself there. Go to "Configure Settings" in the "Game Settings" tab in the upper right navigation bar, and select the Lock View module.

In the Lock View settings, under "User Configuration," you can individually configure each user you've set up in your world. Just uncheck "Enable" for the user, and all effects of Lock View will no longer apply to them.

Under "Scene Configuration," you get a comprehensive list of all the scenes in your world and can see and individually set settings for each scene.
